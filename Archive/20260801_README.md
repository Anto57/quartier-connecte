# Quartier connecté

## Présentation

Quartier Connecté est une plateforme open source permettant de déployer :

- un hotspot Wi-Fi sécurisé
- un portail captif moderne
- une plateforme communautaire de quartier
- un espace dédié aux commerces
- une interface d'aide aux livreurs
- un système de signalement et d'entraide

Le premier déploiement sera :

> **Mermoz WiFi – Le quartier connecté**

---

## Objectifs

Créer une solution simple à installer et réutilisable dans n'importe quel quartier.

---

## Technologies

- Debian
- Hostapd
- OpenNDS
- Python / FastAPI
- PostgreSQL
- HTML / CSS / JavaScript
- Docker (backend uniquement)
