# Vision du projet

## Notre objectif

Créer une solution libre permettant à n'importe quel quartier, résidence, commerce ou collectivité de déployer facilement :

- un hotspot Wi-Fi sécurisé ;
- un portail captif moderne ;
- une plateforme communautaire ;
- un espace dédié aux commerces ;
- un module d'information pour les livreurs ;
- un système d'entraide entre voisins ;
- un tableau de bord d'administration.

Le premier déploiement pilote sera :

**Mermoz WiFi – Le quartier connecté**

Le projet devra être facilement réutilisable dans d'autres quartiers simplement en changeant le nom, le logo et les informations locales.
